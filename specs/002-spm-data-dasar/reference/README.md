# Rujukan kepala formulir

`form-headers/form-5a*.header.json` adalah struktur kepala Form 5.A.1 sampai 5.A.12 (isi sel
kepala, sel gabung, dan keterangan kolom) yang diekstrak dari templat kosong SPM BPBD Kota
Banjarmasin TA 2026. Berkas ini tidak memuat data warga dan menjadi "berkas emas" uji ekspor.

Lembar kerja asli (`.xlsx`) tidak disimpan di repositori. Bila format resmi berubah, ekstrak
ulang dari templat kosong yang baru dan perbarui `form_definitions` dengan versi baru.

Lembar Form 5.A.9 tidak memuat baris judul; judul resminya dicatat pada `official_title`.
